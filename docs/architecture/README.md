# 配布版の構成

Engine → Workspace → Mission → Cycle → Action → Artifactの順で作業を分けます。実行規則はGlobal Skill、目的・受入条件はMission、実際の進行位置はSTATEを正本とします。

この版は手動の8工程運用です。ブラウザrunnerや本番配備を含めません。設計図は [diagrams.md](diagrams.md)、工程の責務は [stage-boundary.md](stage-boundary.md) を参照してください。

Step 8では実装・Skill・説明の食い違いを照合します。文書に合わせるために、権限や受入条件を黙って弱めません。
