# 担当別の保存先

共通配布元は手順の取得・改善の還元に使い、通常業務のMissionやSTATEを書き込みません。利用者が指定した独立した作業repoを使います。privateを既定とし、repo作成・公開・削除・自動運転はそれぞれ実際の依頼と権限を確認します。

作成時は配布版を固定し、新しい履歴へ必要なファイルだけコピーします。元の `.git`、Mission・会話履歴・実原稿・runtime・認証情報は持ち込みません。保存先と通常writerの実sessionを照合し、未割当なら作成者IDを代入せず未割当のまま保持します。

目的・成果・受入条件が未設定なら `awaiting_definition / not_started` を保ちます。明示された担当交代では旧writerの停止、未保存・配送不明、差分、再開位置を確認します。安全な引継ぎを確認するまで別セッションを並行writerへ追加しません。

再利用できる改善は [横断改善](../gpt-engine/rules/skill-federation.md) で提案・採否・固定版・実反映を追います。配布元が新しいことだけを理由に担当固有の目的や停止条件を上書きしません。保管先も利用者が指定し、保管済みであることを削除許可にしません。
